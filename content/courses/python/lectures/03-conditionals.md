Умовна конструкція обирає одну з гілок програми залежно від логічного виразу.

```python
score = 82

if score >= 60:
    print("Зараховано")
else:
    print("Спробуйте ще раз")
```

Відступи визначають, які інструкції належать до кожної гілки.

## Практика

Напишіть програму, яка визначає, чи число додатне, від'ємне або дорівнює нулю.

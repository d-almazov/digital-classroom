Змінна пов'язує ім'я зі значенням. Зрозумілі назви допомагають читати програму як пояснення задачі.

```python
course_name = "Python"
week = 2
is_active = True
```

## Основні типи

Рядки `str` зберігають текст, `int` — цілі числа, `float` — дробові, а `bool` — істину або хибу.

## Практика

Створіть змінні для назви книжки, кількості сторінок і ознаки того, чи ви її прочитали.

Програма — це впорядкована послідовність інструкцій, які комп'ютер виконує для отримання результату.

## Перша програма

```python
print("Вітаю у курсі!")
```

Функція `print` виводить значення на екран. Python виконує цей рядок згори вниз.

## Практика

Змініть повідомлення та виведіть окремими рядками своє ім'я і мету навчання.

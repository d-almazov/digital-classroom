Список містить послідовність значень і дозволяє додавати, змінювати та перебирати елементи.

```python
topics = ["змінні", "умови", "функції"]
topics.append("списки")

for topic in topics:
    print(topic)
```

Індекси списку починаються з нуля.

## Практика

Створіть список оцінок і обчисліть їхнє середнє значення.

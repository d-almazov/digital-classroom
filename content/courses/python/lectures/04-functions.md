Функція — це іменований блок коду, який можна викликати багато разів.

```python
def greet(name):
    return f"Привіт, {name}!"

message = greet("Олено")
print(message)
```

Параметр `name` отримує вхідне значення, а `return` повертає результат.

## Практика

Створіть функцію, яка приймає два числа та повертає їхню суму.

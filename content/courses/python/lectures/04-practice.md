Ця практика допоможе перевірити базові навички на невеликих програмах. Код виконується безпосередньо у вашому браузері: натисніть **«Запустити»**, щоб побачити результат, або **«Перевірити»**, щоб порівняти його з очікуваною відповіддю.

## Що потрібно знати

Перед початком пригадайте:

- як створювати змінні та виводити значення через `print()`;
- як виконувати арифметичні операції;
- як працюють `if` та `else`;
- як перебирати послідовність циклом `for`;
- як оголосити функцію за допомогою `def` і повернути значення через `return`.

Не обов'язково виконувати всі вправи одразу. Якщо застрягли, відкрийте підказку, а розв'язання переглядайте лише після власної спроби.

{{< python-exercise
  id="python-variables-01"
  title="Вправа 1. Змінні"
  starter=`name = ""
age = 0

print(name)
print(age)`
  expected-output=`Іван
20`
  hint="Запишіть текстове значення в лапках, а вік — як ціле число без лапок."
  solution=`name = "Іван"
age = 20

print(name)
print(age)`
  next="python-arithmetic-02"
>}}

Створіть дві змінні:

- `name` — ім'я **Іван**;
- `age` — вік **20**.

Виведіть кожне значення з нового рядка за допомогою `print()`.

{{< /python-exercise >}}

{{< python-exercise
  id="python-arithmetic-02"
  title="Вправа 2. Арифметичні операції"
  starter=`a = 15
b = 4

# Виведіть суму, різницю, добуток і частку`
  expected-output=`19
11
60
3.75`
  hint="Використайте чотири окремі виклики print() та оператори +, -, * і /."
  solution=`a = 15
b = 4

print(a + b)
print(a - b)
print(a * b)
print(a / b)`
  next="python-condition-03"
>}}

Для заданих змінних `a = 15` і `b = 4` виведіть у вказаному порядку:

1. суму;
2. різницю;
3. добуток;
4. результат ділення `a` на `b`.

Кожен результат має бути в окремому рядку.

{{< /python-exercise >}}

{{< python-exercise
  id="python-condition-03"
  title="Вправа 3. Умова"
  starter=`age = 20

# Додайте умовну конструкцію`
  expected-output="Повнолітній"
  hint="Перевірте умову age >= 18. Не забудьте про двокрапку та відступи."
  solution=`age = 20

if age >= 18:
    print("Повнолітній")
else:
    print("Неповнолітній")`
  next="python-loop-04"
>}}

Створіть перевірку віку:

- якщо `age` не менше 18, виведіть `Повнолітній`;
- інакше виведіть `Неповнолітній`.

Залиште значення `age = 20`, щоб автоматична перевірка могла порівняти результат.

{{< /python-exercise >}}

{{< python-exercise
  id="python-loop-04"
  title="Вправа 4. Цикл"
  starter=`# Напишіть цикл, який виведе числа від 1 до 5`
  expected-output=`1
2
3
4
5`
  hint="Функція range(1, 6) створює послідовність від 1 до 5 включно."
  solution=`for number in range(1, 6):
    print(number)`
  next="python-function-05"
>}}

За допомогою циклу `for` виведіть числа від 1 до 5. Кожне число повинно з'явитися в окремому рядку.

Не пишіть п'ять окремих викликів `print()` — мета вправи полягає у використанні циклу.

{{< /python-exercise >}}

{{< python-exercise
  id="python-function-05"
  title="Вправа 5. Функція"
  starter=`def square(n):
    # Поверніть квадрат числа
    pass

print(square(5))`
  expected-output="25"
  hint="Квадрат числа — це число, помножене саме на себе. Функція має повернути результат через return."
  solution=`def square(n):
    return n * n

print(square(5))`
>}}

Створіть функцію `square(n)`, яка повертає квадрат переданого числа.

Не змінюйте виклик `print(square(5))`: очікуваний результат програми — `25`.

{{< /python-exercise >}}

## Підсумок

Ви потренувалися створювати змінні, обчислювати вирази, розгалужувати виконання програми, повторювати дії циклом і виділяти логіку у функцію.

Якщо якась вправа була складною, поверніться до відповідної лекції та повторіть її без перегляду розв'язання.

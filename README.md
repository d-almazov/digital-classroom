# Особистий університет

Статичний сайт особистого викладача на Hugo. Проєкт містить каталог курсів, окремі мінісайти курсів, лекції, завдання, ресурси та нотатки. Увесь демонстраційний вміст написано українською.

## Локальний запуск

Потрібен [Hugo](https://gohugo.io/installation/) версії 0.128 або новішої.

```bash
hugo server
```

Сайт буде доступний за адресою, яку виведе Hugo (типово `http://localhost:1313/`).

Для виробничої збірки:

```bash
hugo --gc --minify
```

Результат з'явиться в каталозі `public/`.

## Інтерактивні вправи Python

Python-код виконується повністю у браузері за допомогою [Pyodide](https://pyodide.org/). Сайт не надсилає введений код на сервер і не потребує бекенда. Pyodide завантажується лише після першого натискання **«Запустити»** або **«Перевірити»**; усі вправи на сторінці повторно використовують один runtime у Web Worker.

Щоб додати вправу до будь-якого Markdown-матеріалу, використайте shortcode:

```go-html-template
{{< python-exercise
  id="python-example-01"
  title="Вправа. Змінні"
  starter=`name = ""
print(name)`
  expected-output="Іван"
  hint="Текстове значення потрібно взяти в лапки."
  solution=`name = "Іван"
print(name)`
>}}

Створіть змінну `name` зі значенням `Іван` і виведіть її.

{{< /python-exercise >}}
```

Параметри:

- `id` — обов'язковий унікальний ідентифікатор вправи;
- `title` — видимий заголовок;
- `starter` — початковий код редактора;
- `expected-output` — очікуваний стандартний вивід;
- `hint` і `solution` — необов'язкові приховані блоки;
- `next` — необов'язковий `id` наступної вправи на тій самій сторінці.

Під час перевірки shortcode-незалежний JavaScript запускає код, нормалізує переноси рядків, прибирає пробіли на початку й наприкінці та порівнює результат з `expected-output`. Виконання довше восьми секунд зупиняється перезапуском Web Worker, щоб нескінченний цикл не блокував сторінку.

## Додавання курсу

1. Створіть `content/courses/course-slug/_index.md` за зразком наявного курсу.
2. Додайте `syllabus.md`, `resources.md`, каталоги `lectures/` та `assignments/`.
3. У кожному каталозі створіть `_index.md`; для лекцій задайте каскад `type: lectures`, для завдань — `type: assignments`.
4. Додавайте матеріали з числовим `weight` у front matter.

Шаблони автоматично додадуть курс до каталогу, сформують бічну навігацію, списки матеріалів і переходи між сусідніми лекціями.

## Структура

- `content/` — Markdown і метадані;
- `layouts/` — сторінки та повторно використовувані partials;
- `assets/css/` — типографіка, компоненти, макет і стилі курсу;
- `archetypes/` — заготовки для нового вмісту;
- `.github/workflows/hugo.yml` — збірка й публікація на GitHub Pages.

## GitHub Pages

Workflow запускається після push до `main`. У налаштуваннях репозиторію відкрийте **Settings → Pages** і виберіть **GitHub Actions** як джерело публікації.

Перед ручним розгортанням замініть демонстраційний `baseURL` у `hugo.toml`. Під час GitHub Actions правильна адреса передається команді збірки автоматично.

## Демонстраційні дані

`Ім'я Прізвище`, біографія, курси й навчальні матеріали є вигаданими заповнювачами та не описують реальну людину.
